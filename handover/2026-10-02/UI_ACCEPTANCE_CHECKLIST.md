# 2026-10-02 真机验收清单

## A. 非棋盘视觉（先做）

每个页面至少在一台短屏和一台长屏上检查；问题记录必须包含页面、交互状态、设备分辨率/比例和截图。

- [ ] 主菜单：标题、署名、四入口、设置图标和山水页脚不裁切；大留白与确认稿一致。
- [ ] 主菜单：本机/蓝牙有克制青墨/朱墨差异；联机禁用不是单纯低透明度；按下与焦点无现代发光。
- [ ] 蓝牙大厅：初始、未授权、蓝牙关闭、创建等待、设备列表、连接中、失败、重试、取消、再战邀请状态均无圆角卡片回退。
- [ ] 设置：三项水墨开关点击区域足够；开/关除颜色外还有位置变化；恢复默认可用。
- [ ] 玩法说明：四分类、折叠内容、滚动与走法图放大层均清晰，固定返回与标题不遮挡。
- [ ] 英雄选择：上方详情约 1/4、下方六列名册；选中、未选、确认、禁用与倒计时紧急态可区分。
- [ ] 猜拳：选择出现墨晕、其余变淡；确认后只显示“已定”，具体手势完全隐藏。
- [ ] 对局外围：玩家信息、倒计时、畸变入口、准备控件、双方状态、已吃入口、消息栏和三点菜单统一为水墨体系。
- [ ] 覆盖层：规则/畸变、英雄/技能、已吃、结果、断线、通用确认和 Toast 无圆角现代卡片。
- [ ] 安全区：状态栏、刘海/挖孔、手势导航条不遮挡按钮；字体缩放后关键控件不溢出。
- [ ] 软键盘：消息抽屉输入框可见，键盘弹出不会重排或压缩棋盘核心。

## B. 棋盘保护（同时观察，不主动修改）

- [ ] 棋盘比例、位置、交叉点和触控命中与上一确认版一致。
- [ ] 32 枚棋子锚点、字形、墨圈尺寸与旋转未变化。
- [ ] 选择、合法落点、吃子、陷阱草稿和终结残影正常。

若本区出现差异，先记录为回归问题；不得通过重画或重排棋盘临时掩盖。

- [ ] 双方英雄选择与猜拳保密，不提前公开具体选择。
- [ ] 猎人陷阱坐标/层数只对本人和权威端可见。
- [ ] 正式行棋、聊天、快捷消息、已吃记录和技能公开状态一致。
- [ ] 单方断线、多段累计、双方同时/错峰断线、蓝牙关闭/恢复和自动重连。
- [ ] 累计 60 秒判负与同时阈值平局符合权威结算。
- [ ] 再战邀请接受、拒绝、30 秒超时和新一局秘密状态清理。
