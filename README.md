# 揭棋规则引擎

这是揭棋 H5 项目的最小可玩原型，包含：

- 全局混洗与开局；
- 石头剪刀布；
- 中国象棋基础走法；
- 暗子移动、翻开、倒戈与背刺；
- 自残：可吃己方位置或己方控制的暗子，己方明子不可吃；
- 将军、裁决与无处可逃；
- 权威落子、版本检查和重复请求保护；
- 自动测试；
- 英雄：猎人陷阱、潜行者刺杀/隐身/强击、战士防护壁垒/铁甲；
- 畸变：铁马、铁壁、暗影之舞、战车、出征、骑兵；
- 同一浏览器双人轮流试玩界面：秘密石头剪刀布、英雄与畸变选择、猎人私下布置、刺杀/强击按钮、翻子、吃子、背刺、裁决、无处可逃和臣服；
- Android 第一阶段外壳：将网页试玩版作为离线资源封装进 APK，后续可在此基础上接入近距离蓝牙联机。

当前网页尚未连接远程房间、账号、数据库或云函数；它只在本机运行，暗子真实身份仅保存在当前浏览器内存中，适合规则试玩而不适合正式联机。

不过，联机所需的服务端房间契约已完成于 `src/remote-room.ts`：它包含邀请口令哈希、两席位、秘密猜拳、权威落子、服务端自动结算与公开状态净化；目前没有接入云账号，所以不会影响本地试玩。完整的 CloudBase 对接方案见 [ONLINE-ARCHITECTURE.md](ONLINE-ARCHITECTURE.md)。

## 运行

需要 Node.js 24 或更高版本，无需安装依赖：

```bash
npm test
```

也可以完全绕过 npm，直接运行：

```bash
node --test --test-reporter=spec tests/*.test.ts
```

## 本地试玩

同样不需要安装依赖：

```bash
npm run serve:web
```

浏览器打开终端提示的地址后，两名玩家可轮流在同一台设备上试玩。只想生成静态网页文件时运行：

```bash
npm run build:web
```

生成结果在 `dist/`。

### 手机试玩

把项目下载到一台已安装 Node.js 24 的电脑上，电脑与手机连接同一个 Wi-Fi，然后运行 `npm run serve:web`。终端会显示一个“同一 Wi-Fi 的手机打开”地址；在手机浏览器输入该地址即可。若打不开，请允许 Node.js 通过电脑防火墙的专用网络。

当前验证结果：107 项规则、英雄、畸变与联机边界测试全部通过；背刺与裁决会自动选择终结棋子、播放终结演出，并在动画结束后展示对应胜利文案。

### Android 离线 APK（第一阶段）

`android/` 是一个可直接由 Android Studio 打开的原生工程。它用系统 WebView 加载 APK 内置的游戏页面，不申请网络或蓝牙权限；因此这一版能离线试玩，但还不能让两台手机连接。

先在项目根目录生成并同步网页资源：

```bash
node scripts/build-web.ts
node android/scripts/sync-web-assets.mjs
```

然后在 Android Studio 打开 `android/`，选择 `Build > Build APK(s)`。完整环境要求与 APK 输出位置见 [android/README.md](android/README.md)。第二阶段才会加入 Bluetooth Classic 主机权威结算、配对与断线处理。

## 终局表现

- **背刺**：暗子翻开后若归属对方且直接将军，自动用该棋子终结将/帅；动画结束后显示“暗中潜行，破影而袭！您获得胜利！”
- **裁决**：正面将死后，系统自动使用将军子终结将/帅；动画结束后显示“圣光的正义终结了敌人！您获得胜利！”
- **无处可逃**：未被将军但无任何合法走法，对方直接获胜。
- **臣服**：玩家主动认输；胜者看到“对方已臣服于您，获得胜利！”。

“虚空放逐”是未来远程房间的断线结算文案；本地双人试玩不具备网络连接，因此不会触发该状态。

## 目录

```text
src/    纯规则模块与服务端房间契约
tests/  自动测试
web/    本地试玩界面
scripts/ 零依赖构建与本地静态服务器
android/ Android 离线 APK 外壳与网页资源同步脚本
```

规则依据为《揭棋规则规格 v1》冻结稿。

## 后续玩法设计

三名英雄与六项畸变的已确认规则、服务器状态、结算顺序和测试要求见 [HERO-MUTATION-SPEC.md](HERO-MUTATION-SPEC.md)。它们已经接入权威引擎与房间状态：猎人坐标仅保存在玩家私有视图；战车/铁马路径碾碎、乱杀、两败俱伤和“碾碎他们！”都由服务端结算；每次操作公开记录路径碾碎和壁垒弹回，供两端一致播放。

仍未接入真实的 CloudBase 账号、云函数和数据库，因此本地网页不能直接跨设备联机；现有 `remote-room.ts` 是可迁入云函数的无状态房间契约，数据边界和幂等校验已经包含在内。
