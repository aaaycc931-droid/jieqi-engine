# 乐子象棋规则引擎

> **规划与实现边界（2026-09-18）：** 功能性 UI 与新一轮规则规划已经收口，见 [CONFIRMED_UI_PLAN.md](CONFIRMED_UI_PLAN.md) 和 [BALANCE_AND_RULE_UPDATES.md](BALANCE_AND_RULE_UPDATES.md)。当前代码与 135 项测试仍是旧实现基线，新潜行者、稀有度/宿命、累计断线 60 秒、阶段菜单和新再战流程尚待实现，不能把测试通过理解为这些新决定已经完成。

这是“乐子象棋”的 H5 可玩版本与权威规则引擎，包含：

- 全局混洗与开局；
- 石头剪刀布；
- 中国象棋基础走法；
- 暗子移动、翻开、倒戈与背刺；
- 自残：可吃己方位置或己方控制的暗子，己方明子不可吃；
- 将军、裁决与无处可逃；
- 权威落子、版本检查和重复请求保护；
- 自动测试；
- 英雄：猎人陷阱、潜行者刺杀/隐身/强击、战士防护壁垒/铁甲；
- 畸变：铁马、堡垒、暗影之舞、战车、亲征、骑兵（协议 ID 保持兼容）；
- 固定开局流程：60 秒英雄选择 → 石头剪刀布决定先手 → 创建棋局并公布畸变 → 英雄水墨入场 → 最多 60 秒英雄准备 → 正式行棋；
- 同一浏览器双人轮流试玩界面：整页英雄选择、秘密石头剪刀布、猎人私下布置、刺杀/强击按钮、翻子、吃子、背刺、裁决、无处可逃和臣服；
- Android 蓝牙双机模式：已配对设备通过 Bluetooth Classic RFCOMM 建房/加入；房主权威结算，来宾只提交操作并接收自己的私有视图。

普通浏览器仍只提供本机试玩；Android APK 中则提供蓝牙双机房间。蓝牙房主持有完整房间和暗子身份，来宾仅接收已净化棋盘、自己的英雄选择和自己的陷阱坐标；两者都不依赖网络、账号、数据库或云函数。

不过，联机所需的服务端房间契约已完成于 `src/remote-room.ts`：它包含邀请口令哈希、两席位、秘密猜拳、权威落子、服务端自动结算与公开状态净化；目前没有接入云账号，所以不会影响本地试玩。完整的 CloudBase 对接方案见 [ONLINE-ARCHITECTURE.md](ONLINE-ARCHITECTURE.md)。

## 运行

需要 Node.js 24 或更高版本，无需安装依赖：

```bash
npm test
```

也可以完全绕过 npm，直接运行：

```bash
node --test --test-reporter=spec tests/*.test.ts
```

## 本地试玩

同样不需要安装依赖：

```bash
npm run serve:web
```

浏览器打开终端提示的地址后，两名玩家可轮流在同一台设备上试玩。只想生成静态网页文件时运行：

```bash
npm run build:web
```

生成结果在 `dist/`。

### 手机试玩

把项目下载到一台已安装 Node.js 24 的电脑上，电脑与手机连接同一个 Wi-Fi，然后运行 `npm run serve:web`。终端会显示一个“同一 Wi-Fi 的手机打开”地址；在手机浏览器输入该地址即可。若打不开，请允许 Node.js 通过电脑防火墙的专用网络。

当前验证结果：135 项旧基线规则、英雄、畸变、蓝牙房主、联机边界与界面流程测试全部通过；背刺与裁决会自动选择终结棋子、播放终结演出，并在动画结束后展示对应胜利文案。

### Android 蓝牙双机 APK

`android/` 是一个可直接由 Android Studio 打开的原生工程。它用系统 WebView 加载 APK 内置页面，不申请网络权限；Android 12+ 仅在第一次使用蓝牙入口时请求“附近的设备”连接权限。两台手机在系统设置配对后，一台创建房间、另一台选择已配对房主加入，即可依次完成选英雄、猜拳、入场、英雄准备和对弈。

先在项目根目录生成并同步网页资源：

```bash
node scripts/build-web.ts
node android/scripts/sync-web-assets.mjs
```

然后在 Android Studio 打开 `android/`，选择 `Build > Build APK(s)`。完整环境要求与 APK 输出位置见 [android/README.md](android/README.md)。

## 终局表现

- **背刺**：暗子翻开后若归属对方且直接将军，自动用该棋子终结将/帅；动画结束后显示“暗中潜行，破影而袭！您获得胜利！”
- **裁决**：正面将死后，系统自动使用将军子终结将/帅；动画结束后显示“圣光的正义终结了敌人！您获得胜利！”
- **无处可逃**：未被将军但无任何合法走法，对方直接获胜。
- **臣服**：玩家主动认输；胜者看到“对方已臣服于您，获得胜利！”。

“虚空放逐”是未来远程房间的断线结算文案；本地双人试玩不具备网络连接，因此不会触发该状态。

## 后续玩法设计

三名英雄与六项畸变的已确认规则、服务器状态、结算顺序和测试要求见 [HERO-MUTATION-SPEC.md](HERO-MUTATION-SPEC.md)。它们已经接入权威引擎与房间状态：未确认的英雄选择和猎人坐标仅保存在玩家私有视图；战车/铁马路径碾碎、乱杀、两败俱伤和“碾碎他们！”都由服务端结算；每次操作公开记录路径碾碎和壁垒弹回，供两端一致播放。
