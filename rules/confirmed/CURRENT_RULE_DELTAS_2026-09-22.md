## 1. 正式术语总原则

### 1.1 正式“走棋”分类退役

正式规则不再把“走棋”作为上位行动分类。正式主行动只有：

- 【移动】
- 【进攻】

自然语言仍可说“走一步棋”，但正式规则迁移如下：

- “不能进行走棋” → “不能进行【移动】或【进攻】”
- “成功走棋后” → “成功完成【移动】或【进攻】后”
- “位移不属于走棋” → “【移置】不是【移动】或【进攻】”
- “重新走棋” → 按来源写成“重新执行一次规定范围内的【移动】或【进攻】”

旧【吃子】行动词继续保持退役；普通吃子属于【进攻】。

### 1.2 当前分类型词表

不再使用“13行动关键词”“通用效果词”两个旧总称。当前按类型分组：

- 核心行动词：【移动】、【进攻】
- 技能标签：【占步】
- 行动标签：【额外】、【强迫】
- 结算标签：【触发】、【连带】
- 资源标签：【耗费】
- 控制标签：【操控】
- 终局标签：【终结】
- 信息标签：【揭示】
- 生成标签：【随机】
- 规则操作词：【回溯】
- 位置效果词：【移置】
- 进攻标签：【强击】
- 消灭方式词：【碾碎】、【窒息】
- 结果词：【消灭】
- 状态词：【感染】
- 空间状态词：【地面】、【飞行】
- 目标状态词：【无形】
- 抗性关系词：【免疫】
- 限制关系词：【封锁】

## 2. 【终结】、【消灭】与“将军”严格分层

### 2.1 【消灭】

【消灭】是棋子级结果：一枚存活棋离开当前存活棋盘。

- 不要求存在“吃它的人”；
- 【进攻】、【强击】、【碾碎】、【窒息】、陷阱、【感染】、时间崩坏等均可导致【消灭】；
- 【消灭】本身不等于对局终结。

### 2.2 【终结】

【终结】是对局流程标签：规则使普通对局进入胜/负/和结算。

- 【终结】不要求之前发生【消灭】；
- 将死、困毙、认输、断线、秦龙雨夜等可直接进入【终结】；
- 将帅因某来源被【消灭】时，可进一步触发对应【终结】，两层应分别记录。

### 2.3 将军

“将军”只是一种棋盘威胁状态：

- 不是【进攻】；
- 不是【终结】；
- 来源规则决定后续流程。

普通将军 → 正常应将；普通将军且无合法应对 → 裁决【终结】；背刺/秦龙雨夜等来源可让将军直接进入专属【终结】。

未来实现不得再让单一 `isSquareAttacked` 同时承担“威胁存在”和“是否自动终结”两种职责。

### 2.4 原子结算中的统一【终结】检查点

多步骤原子结算统一采用：

> **候选终局 → 原子闭合 → 正式【终结】**

- 原子结算中途若将/帅进入【消灭】，先形成“候选终局”，不立即截断该次已经合法发动且不可分割的来源结算；
- 同一来源中为确定最终棋盘状态所必需的已承诺后续步骤、强制返回/落位/【移置】、依附本次落位的直接【触发】、死亡【揭示】与已消灭记录继续完成；
- 到原子闭合点后统一检查双方将帅最终状态，再正式【终结】；
- 正式【终结】后停止回合切换、持续时间正常递减、下一回合/回合末刷新、无关新触发、新技能机会与玩家决策；
- 结果落盘、事件日志、必要状态版本与终局动画/UI 属于结果持久化/表现层，不视为继续游戏；
- 认输、断线等无待闭合棋盘原子行动的独立直接终局可直接【终结】。

“候选终局”是结算状态，不新增为正式关键词。

### 2.5 将帅【消灭】来源与权威终局 reason

新增稳定 reason ID：

| 将帅最终【消灭】直接原因 | reason ID | UI 名称 | 胜方播报 |
|---|---|---|---|
| 三层【感染】结算 | `infection` | 感染 | 感染蔓延，将帅已被消灭！您获得胜利！ |
| 【窒息】 | `suffocation` | 窒息 | 将帅因窒息被消灭！您获得胜利！ |
| 时间崩坏到期 | `time_collapse` | 时间崩坏 | 时间崩坏吞没了将帅！您获得胜利！ |
| 未配置专属终局映射的其他【消灭】来源 | `general_destroyed` | 将帅陨落 | 敌方将帅已被消灭！您获得胜利！ |

规则：

- `general_destroyed` 仅为兜底，不覆盖已有专属 reason；
- 既有 `ambush / checkmate / stalemate / resign / disconnect / trap_ambush / crush_them / rampage` 等继续有效；
- 【感染】、【窒息】、时间崩坏杀将不是 `checkmate`；
- winner 与 reason 分离，reason 描述直接终局来源，胜负由最终将帅/对局状态判定；
- 同一原子结算闭合后双方将帅均【消灭】时，最终 outcome reason 为 `mutual_destruction`；各自具体死亡来源保留在事件日志中；
- reason ID 作为稳定 wire value；以后只改 UI 文案时不应无必要改动 ID。

## 3. 【消灭】的正式用词与状态终止

### 3.1 “死亡 / 杀死 / 击杀”退回自然语言层

正式规则中统一写：

- “使目标【消灭】”
- “目标进入【消灭】结果”
- “消灭事件”

“死亡、杀死、击杀”可继续用于播报、动画、统计文案，但不再承担独立规则语义。

### 3.2 退役“先清除效果再击杀”通用模板

棋子进入【消灭】结果时，默认**不会先执行一次独立的“清除全部效果”**。

- 【碾碎】地面+无形棋：直接【消灭】，不是先移除【无形】；
- 【窒息】带防御棋：直接【消灭】，不是先触发“防御被清除”；
- 三层【感染】结算：直接【消灭】；
- 【强击】不靠“先清掉防御/无形”来取得目标资格。

只有来源明确规定某状态被消耗、清除或解除时，才产生独立状态变化。

### 3.3 状态退出术语边界

- 【耗费】：有限资源被实际扣除，如陷阱层、技能次数、弹药。
- 清除：规则主动移除仍存在的状态/区域/效果。
- 失效 / 终止：因期限、条件消失或对象退出有效状态而停止。
- 净化：世界观/技能描述词，底层仍按来源规定的“清除”执行。

棋子被【消灭】后，其只对存活棋有效的临时状态因对象退出存活棋盘而终止；这不视为逐项“清除”。

## 4. 暗子【揭示】与已消灭棋子记录

### 4.1 通用死亡揭示

任何仍处于暗置/隐藏身份的棋，一旦实际进入【消灭】结果，必须同步执行【揭示】并公开其真实身份，再进入当前“已消灭棋子记录”。

该【揭示】只是信息公开，不等于该暗子完成了正常【移动】或【进攻】的“成功落位后揭示”。

正常存活揭示仍是：暗来源成功完成预定【移动】或【进攻】落位后再【揭示】。

### 4.2 【混乱】专属例外

【混乱】局中，尚未正常揭示的暗子被【消灭】时：

- 仍执行死亡【揭示】；
- 只公开真实兵种；
- 不公开其死亡时的秘密阵营；
- 已消灭记录显示兵种，但阵营标记为“未锁定 / 隐藏”，不得为归组而泄露秘密阵营。

若该棋此前已经正常揭示并永久锁定阵营，则按公开阵营正常记录。

### 4.3 统一“已消灭棋子记录”

旧“已吃棋子记录”退役。权威状态建立统一“已消灭棋子记录”：

- 所有实际进入【消灭】的棋都进入记录，不论来源；
- 归属按被消灭棋的真实身份/已公开阵营，而不是按“谁杀了它”；
- 普通进攻、强击、碾碎、陷阱、感染、窒息、时间崩坏、自残等均使用同一记录；
- 若棋被复活，当前权威“已消灭”状态应移除该棋；
- 完整【回溯】则按历史快照恢复当前权威记录；
- 历史事件日志可保留曾发生的消灭事件，但不能把当前已存活棋继续算作“已消灭”。

UI 中“已吃棋子”同步改名为“已消灭棋子”。

## 5. 【无形】、【地面】、【飞行】

### 5.1 【无形】只改变“能否被直接指定”

【无形】不改变棋子的空间存在。

只要棋仍拥有【地面】，就正常参与：

- 占格；
- 车等地面路径阻挡；
- 炮架；
- 马腿；
- 象眼；
- 将帅照面等依赖地面位置的判定。

只有失去【地面】才不再参与这些地面空间判定。

旧规则“无形不阻挡路径 / 不当炮架 / 不当马腿 / 不当象眼”全部退役。

【无形】本身也**不取消攻击范围或有效将军**：

- 一枚拥有【无形】的棋，仍按自身兵种/来源规则产生正常攻击几何；
- 若该威胁在其他规则下合法触及敌方将/帅，原则上仍可形成有效将军；
- 若来源另有“不能【进攻】/不能将军”等限制，优先按来源专属限制执行；例如【飞行】同时规定不能【进攻】，不能从【无形】通用规则反推出飞行棋可进攻/将军；
- 潜行者技能赋予的【无形】是来源专属例外：该【无形】存续期间棋子保留正常攻击几何，但**不产生有效将军**。该限制属于潜行者技能，不属于【无形】通用性质。

#### 【无形】×【随机】目标选择

【随机】从规则定义的候选集合中抽取对象，不属于“直接指定”具体棋子。

- 玩家/效果明确选择某一枚具体棋作为目标 → 属于直接指定，默认不能直接指定【无形】棋；
- 先建立合法候选池，再由系统【随机】确定对象 → 不属于直接指定，【无形】棋默认仍进入候选池；
- 即使候选池中只剩一枚【无形】棋，也可以被随机抽中；
- 被随机抽中后按来源规则直接结算，不需要先清除【无形】；
- 只有来源明确写出“排除【无形】”时，才把【无形】棋排除在随机候选池之外。

### 5.2 【飞行】

【飞行】使棋子：

- 获得【无形】；
- 失去【地面】；
- 免疫【碾碎】；
- 不能进行【进攻】；
- 不占地面层，同坐标可同时存在一枚地面棋和一枚飞行棋；同坐标空中层最多一枚飞行棋。

飞行不自动无视【封锁】。

### 5.3 飞行降落与【窒息】

飞行按来源规定尝试降落：

1. 无地面棋 → 正常重新获得【地面】；
2. 有地面棋 → 对地面棋尝试【碾碎】；
3. 地面棋被【消灭】 → 飞行棋完成降落；
4. 地面棋因免疫/阻止【碾碎】而存活 → 地面层仍不可用，飞行棋遭受【窒息】并【消灭】。

旧“降落失败后继续飞行等待重试”退役。

【免疫·碾碎】不等于免疫【窒息】；只有明确“免疫【窒息】”才可阻止。

## 6. 【移置】、复活与【回溯】

### 6.1 【移置】

【移置】是存活棋因规则/技能/效果改变位置，但不属于【移动】或【进攻】。

默认：

- 成功落位后按普通落位规则结算；
- 落位非法时通常留在原位，除非来源另有失败处理；
- 战士弹回与飞行降落冲突属于明确来源例外。

### 6.2 复活

“复活”暂不升格为正式关键词。

复活表示：棋子的死亡事实已经发生，之后重新恢复为存活棋并返回棋盘。

复活恢复“存活本体”，**不恢复死亡前完整状态快照**：

- 感染从 0 层开始；
- 无形不保留；
- 飞行不保留，复活以【地面】棋落位；
- 战士普通防御与剩余持续层不保留；
- 时间崩坏不保留；
- 其他只对存活棋有效的临时附着效果默认不保留。

身份级/历史级/资源级信息不因此重置，例如已【揭示】、时光勇士身份、曾占用战士防御名额、英雄技能已使用次数等。

### 6.3 【回溯】

【回溯】恢复规定的历史快照。被恢复的变化不视为“重新发生”。

诺兹多姆完整权威快照恢复属于【回溯】，不拆成大量【移置】或复活。

时光沙漏的局部回锚点不是【回溯】：

- 存活时光勇士 → 【移置】回锚点；
- 已死亡时光勇士 → 复活到锚点。

## 7. 【窒息】

【窒息】是独立的消灭方式词：

> 当具体来源要求某棋必须占据、返回或降落到某一位置，但该位置的空间冲突按该来源规则无法解除时，由来源指定的棋直接进入【消灭】结果。

当前只确认两类来源：

1. 战士普通防御弹回：攻击者必须【移置】回进攻前位置；若来源规则下返回格因空间冲突无法容纳攻击者，则攻击者【窒息】并【消灭】。
2. 飞行规定降落：地面占用者在降落【碾碎】后仍存活，则飞行棋【窒息】并【消灭】。

不要把所有非法落位自动推广为【窒息】。

## 8. 战士普通防御

### 8.1 获得

- 每局最多 3 枚不同的己方非将帅明棋可获得普通防御；
- 棋子首次通过【移动】或【进攻】成功离开己方九宫时获得；
- 某棋一旦曾获得过，之后消耗、失效、死亡、复活或重新入宫都不会重新获得；
- 三个资格名额一旦被不同棋占用不返还；
- 将帅不获得普通防御。

### 8.2 效果

普通防御只介入**直接指定该棋、且不带【强击】的【进攻】**。

触发时：

1. 防御立即耗尽；
2. 目标存活并留在原位；
3. 进攻者必须通过【移置】返回进攻前位置；
4. 成功返回后按返回格正常结算；
5. 进攻者没有成功落到目标格，因此目标格不结算进攻者的落位效果；
6. 若来源专属返回规则下因空间冲突不能返回，进攻者【窒息】并【消灭】。

战士普通防御的“返回进攻前原位”是【堡垒】封锁的**来源专属例外**：

- 若进攻者在本次【进攻】开始前已经合法位于敌方九宫内，随后向九宫外目标发动【进攻】并被战士普通防御拦截，则返回该进攻前原位的【移置】不受【堡垒】“九宫外不得重新进入”的封锁；
- 该例外只适用于战士普通防御要求的本次进攻前原位复位，不扩展到其他【移置】、复活、技能回归或主动进入；
- 返回原位仍必须满足来源专属空间可容纳条件；若因占位/空间冲突无法容纳，仍按本节【窒息】规则处理。

补充边界：

- 成功弹回属于【移置】成功落位，返回格的陷阱/区域等按普通落位规则结算；
- 暗进攻者被成功弹回时，因为没有完成本次【进攻】预定目标格的成功落位，仍保持暗置；
- 若该暗进攻者在返回失败中因【窒息】进入【消灭】，则按通用死亡规则同步【揭示】；
- 返回失败导致【窒息】时，进攻者不会先在返回格成为一枚新的存活【地面】棋，因此不先触发“成功落位”类陷阱/感染结算。

### 8.3 持续

获得时 3 层持续时间；每个敌方正式回合结束时若仍存在则 -1，至 0 失效。正好覆盖 3 个完整敌方正式回合；额外行动/应将不额外扣层。

## 9. 战士将帅铁甲 × 潜行者

铁甲只免疫一次**背刺终结结果**，不是普遍【强击】免疫。

潜行者在自己正式回合用【进攻】+【强击】攻击战士将帅并本应触发背刺时：

- 铁甲耗尽；
- 背刺终结被阻止；
- 本次强击机会耗尽；
- 潜行者攻击棋不落到将帅格，留在强击前原位；
- 潜行者自己的【无形】结束；
- 若该棋从原位仍对将帅构成普通威胁，则转为普通将军；
- 潜行者当前回合结束；
- 战士按正常下一正式回合应将，不获得【额外】回应。

只有背刺是在**战士自己的正式回合**因揭示/倒戈/自回合事件产生并被铁甲拦截时，才授予一次【额外】+【强迫】的即时应将行动。

## 9A. 潜行者刺杀当前生命周期

当前规则覆盖旧“发动回合可立即强击”的版本：

- 每个刺杀来源每局一次，来源彼此独立；
- 发动时选择己方控制的明棋，不能是将/帅；
- 发动回合只允许该棋通过一次合法【移动】到空位，不能在该回合执行【进攻】或【强击】；
- 该次【移动】成功后获得来源【无形】；
- 该潜行者来源【无形】存续期间，该棋保留正常攻击几何，但不产生有效将军；
- 对手获得完整一个正式回合；
- 到潜行者下一正式回合，该棋可按自身普通进攻几何执行一次【进攻】+【强击】；
- 【强击】可以以敌方将/帅为目标，成功时可触发背刺【终结】；
- 该棋开始执行自己的行动前，潜行者来源的【无形】先按技能生命周期结束；若本回合没有使用保留的【强击】，该次强击机会随该棋本次行动结束而失效；
- 【强击】不天然穿透【无形】，不能因此直接指定原本不可被直接指定的目标。

战士将帅铁甲与该流程的交叉按第 9 节执行。

## 10. 猎人陷阱

### 10.1 触发统一条件

当棋子通过【移动】、【进攻】、【移置】、复活落位或成功飞行降落，成功成为敌方猎人陷阱格上的【地面】棋时，进入陷阱检查。

活棋触发还需同时满足：

1. 位置改变前由陷阱主人的敌方控制；
2. 落位/揭示/控制变化后，在陷阱结算时仍由陷阱主人的敌方控制。

防止猎人利用己方暗子低成本验身份。

### 10.2 生命周期

每层初始寿命 12：

- 敌方正式回合 1–9：致死陷阱；
- 敌方正式回合 10–12：控制陷阱；
- 每个敌方正式回合结束时未消耗陷阱 -1；
- 归零失效；
- 额外行动、应将等不单独扣寿命。

控制陷阱使触发棋在其控制方**下一次正式回合**不能执行【移动】或【进攻】；仅限制该棋，控制者仍可选择其他棋。

## 11. 死亡骑士【感染】与亡魂

当前规则覆盖旧“感染绑定格/亡魂”描述：

- 【感染】绑定棋子；
- 亡魂是格上的持续影响，不是单位；
- 棋从一个有效感染影响格移动到另一个有效影响格，感染层数保持；
- 进入另一个亡魂格不会立即 +1；只在对应死亡骑士方正式回合结束时结算；
- 成功到达无有效感染影响的格后清除感染；
- 失去【地面】立即清除感染；
- 同方同格最多一亡魂，重复合格死亡刷新该亡魂寿命，不立即感染、不重置已有感染层；
- 红黑亡魂可以同格共存并分别结算；
- 亡魂有 3 次所属死亡骑士方正式回合末结算机会；第 3 次结算后消失；
- 每次结算对合格敌方地面棋 +1【感染】，达到 3 层立即【消灭】；
- 感染死亡不是【进攻】，普通防御和铁甲不能阻止；
- 地面+无形棋仍可感染。

## 12. 铁马、战车与骑兵

### 12.1 铁马

对合法马目标检查唯一马腿格的【地面】层：

- 有地面棋 → 对其尝试【碾碎】，随后继续马步；
- 无地面棋 → 视为没有马腿阻挡；
- 地面+无形仍算马腿；
- 飞行棋不算马腿且不受碾碎。

主行动分类按行动计划阶段的杀伤性质确定：

- 马腿格无【地面】棋、最终落点为空 → 【移动】；
- 马腿格无【地面】棋、最终落点为合法杀伤目标 → 【进攻】；
- 马腿格存在【地面】棋，所选路线必然先尝试【碾碎】该马腿棋 → **主行动从一开始就是【进攻】**，无论最终落点是否为空；
- 马腿棋是己方棋，或具有【免疫·碾碎】而最终未被【消灭】，都不改变该主行动属于【进攻】；
- 若最终落点另有合法目标，整个过程仍只记录一个主行动【进攻】，路径【碾碎】与最终目标结算属于同一原子行动；
- 普通【移动】完成后踩中猎人陷阱等后续【触发】不会反向把主行动改成【进攻】。

### 12.2 战车

发动路径只统计起点与目标之间所有拥有【地面】的路径棋：

- 恰好 1 枚地面路径棋 → 可发动并对该棋【碾碎】；
- 地面+无形照常计数；
- 飞行不计数且不受碾碎。

若对敌将的唯一可执行路线必然同时【碾碎】进攻方自己的将帅、从而只能产生“两败俱伤”平局，则该路线**不构成有效将军**。

但若战车实际合法发动并在同一原子结算中使双方将帅都【消灭】，仍按“两败俱伤”平局【终结】。

### 12.3 骑兵

每方真实身份为马的两枚棋，在【揭示】为马后升级为【骑兵】。

- 暗置时无标记、无额外走法；
- 揭示为马后保留完整马步与马腿；
- 己方半场额外获得 1 格向前；
- 敌方半场额外获得 1 格向前 / 左 / 右；
- 这些额外一格按目标占用可成为【移动】或【进攻】；
- “不能后退”只约束额外一格走法，不限制正常马步；
- 骑兵与铁马互斥。

旧固定 1/3/5 路兵位升级方案退役。

## 13. 【堡垒】与【封锁】

【堡垒】对敌方九宫形成【封锁】：

> 敌方棋若当前位于九宫外，不得通过【移动】、【进攻】落位、【移置】或复活落位进入该九宫。

- 已在九宫内的敌棋可在宫内行动并离开；离开后不能重新进入；
- 飞行不自动绕过；
- 无形、强击不自动绕过；
- 封锁限制进入/落位，不自动阻断攻击线；
- 完整历史【回溯】不是一次新的进入，因此可恢复到历史九宫位置。

战士普通防御要求攻击者返回本次【进攻】前原位时，按第 8.2 节来源专属例外处理：该复位【移置】可忽略【堡垒】外到内封锁，但其他进入方式不因此获得豁免。

## 14. 时间机制

### 14.1 姆诺兹多

每局一次【占步】技能：目标为对手紧接着上一正式回合完成的 Ⅰ级“俗手”中的那枚棋；该棋必须仍存活在棋盘。

结算：

1. 目标【移置】回上一行动前位置；
2. 结算返回格效果；
3. 若仍存活，姆诺兹多【操控】同一敌棋执行一次来源允许的合法【移动】或【进攻】；
4. 技能结束当前正式回合。

补充：

- 目标退回属于【移置】；返回格的陷阱/区域等先正常结算；
- 若退回失败，或目标在返回格结算中已经【消灭】，则不再进入后续【操控】步骤；
- 若目标因返回格控制陷阱获得“下一正式回合不能【移动】/【进攻】”限制，该限制从相关控制方的下一正式回合生效，不取消姆诺兹多当前技能链中紧接着发生的这一次【操控】行动。

不会复活上一手被消灭的其他棋，也不会恢复其他历史状态。

### 14.2 诺兹多姆

完整快照【回溯】；每局一次，己方正式回合前 10 秒内且当前未被将军时可用。

- 回到上一己方行动前的完整权威快照，包括当时棋盘状态与双方英雄技能状态；
- 快照之后发生的技能次数/充能、层数、冷却、进度和临时英雄状态变化随时间线恢复；
- “回溯已使用”属于时间线外元状态，不恢复；
- 必须由上一时间线中同一枚棋重新执行一次规定行动；
- 重新行动不能【进攻】，也不能形成将军。

### 14.3 时间崩坏

旧“时间崩坏绑定某一个具体扭曲格”退役。

当前：

- 时空扭曲炸弹直接命中当前格时，可直接获得时间崩坏；
- 诺兹多姆阵营棋只要通过一个合法结算**成功成为有效时空扭曲格上的【地面】棋**，就立即获得时间崩坏；
- 因此【进攻】成功落位、【移置】成功落位、复活成功落位、【飞行】成功降落到有效扭曲格，均获得时间崩坏；
- 普通主动【移动】到空扭曲格本身仍然非法，不能因为统一触发条件而获得新的进入许可；
- 复活不继承死亡前旧时间崩坏，但若新的复活落位本身落在有效扭曲格，会因这次新落位重新获得；
- 时光沙漏仍先检查锚点合法性；锚点已有时空扭曲时本次回归/复活先失败，不会先落位再依靠后续净化；
- 获得后，只要棋连续处于任何有效时空扭曲格，时间崩坏持续；
- 从扭曲 A 到扭曲 B 不清除、不重置截止时间；
- 成功到达无有效扭曲的格或相关扭曲被清除时解除；
- 截止点仍是获得状态后诺兹多姆方下一次正式回合结束；
- 若棋在该次落位后的其他结算中立即【消灭】，时间崩坏随其退出存活棋盘而终止。

### 14.4 时光沙漏

严格顺序更新为：

> 候选锁定 → 锚点合法性检查 → 群体回归/复活 → 各自落位效果结算 → 净化全部时空扭曲 → 无限龙装填

- 时光勇士第一次发生任何公开【揭示】时即取得“已现身”历史状态；通用死亡【揭示】同样有效；
- 暗置时光勇士因陷阱、【碾碎】、【感染】、【窒息】、时间崩坏等非吃子方式【消灭】并死亡【揭示】后，立即算“已现身”，之后属于沙漏的已现身候选集合；
- “已现身”属于身份级/历史级信息，不因死亡、复活或临时状态重置而丢失；
- 存活勇士通过【移置】回锚点；
- 死亡勇士复活到锚点；
- 成功成为锚点【地面】棋后立即按普通落位规则结算陷阱、区域等；
- 锚点若发动瞬间已有棋或处于时空扭曲，本次回归先失败，不能等后续净化后再补回；
- 单个勇士在落位效果中再次【消灭】不阻止沙漏继续完成后续全局步骤。

## 15. 太子——无忧的术语迁移

第 1–9 个完整双方回合内，【无忧】有效时：

- 敌方棋可通过合法【移动】进入、停留、移动或离开太子方半场；
- 敌方棋只要当前位于太子方半场，就不得主动执行【进攻】；
- 敌方也不得通过一次【进攻】把进攻棋落入太子方半场；
- 位于太子方半场的敌棋自身不产生有效将军；
- 半场外远程棋形成的将军不因【无忧】自动失效。

第 1–9 回合内，如果太子方在自己的正式回合：

- 主动完成一次【进攻】，且该【进攻】的最终目标因此进入【消灭】结果；或
- 形成有效将军；

则【无忧】立即暂时失效，对手紧接着的正式回合不受半场保护限制；到太子方下一正式回合开始时若仍在第 1–9 完整回合区间则恢复。

- 发起进攻但被防御拦截、目标未【消灭】 → 不触发暂失；
- 强击成功使最终目标【消灭】 → 触发；
- 陷阱、感染等自动消灭敌棋 → 不算太子方“主动争斗”；
- 铁马主行动分类已按第 12.1 节冻结；【无忧】是否暂失仍严格按本节“最终目标因该【进攻】进入【消灭】或形成有效将军”的条件判断，不因路径存在【碾碎】而另加独立触发。
