## 1. 潜行者最新规则差分

旧规格中“发动当回合可立即强击”“强击可选隐身/无形目标”等条款已过时。

当前确认：

- 潜行者每个刺杀来源一次；
- 发动时选择己方控制的明棋，不能是将帅；
- 发动回合只能把该棋移动到合法空位，**不能在发动当回合使用强击**；
- 之后该棋获得【无形】；
- 对手获得完整一回合；
- 到下一己方回合，该棋可按自身普通进攻几何使用一次【强击】；
- 强击可以以敌方将帅为目标；
- 成功强击敌方将帅触发**背刺**终局；
- 强击机会使用后结束；若该棋开始执行自己的行动，则按潜行者技能专属生命周期先解除【无形】再执行允许的行动；
- 【无形】目标不能被其他强击直接选中，因为强击需要直接选择目标；
- 战士将帅铁甲可阻止潜行者强击杀将：铁甲破裂，将帅存活，强击消耗，无形结束，转为普通将军，战士获得一次额外立即应将。

当前潜行者重评候选：**52/100，合理区间 49–55，中等置信度**。此评分属于本轮重评结果，若旧评分表仍写 49，以本差分为最新设计状态；正式评分主文件尚未写回。

## 2. 死亡骑士｜亡灵之力（本轮已确认冻结）

英雄：**死亡骑士**  
技能：**亡灵之力**  
状态：**感染**  
表现：**凋零**仅为三层感染致死时视觉，不是关键词。

### 2.1 亡魂生成

- 死亡骑士控制的非将/帅棋子实际死亡时，在死亡格生成属于该死亡骑士一方的【亡魂】；
- 死亡原因不限；
- 若死亡同时触发权威终局，终局结算绝对优先，不继续生成/感染等非终局链；
- 归属按死亡瞬间控制方判断，不按棋子初始颜色。

### 2.2 亡魂性质与寿命

- 亡魂不是棋子/单位；
- 可与棋子同格；
- 不阻挡路径，不充当炮架、马腿、象眼；
- 默认不能被选中、移动、消灭或清除；
- 同一拥有者同一格最多一个亡魂；
- 同格再次生成同拥有者亡魂时刷新为完整寿命，不立即加感染，已有感染不重置；
- 红黑死亡骑士的亡魂可同格共存并独立结算。

寿命精确定义：

> 每个亡魂拥有 **3 次“所属死亡骑士一方正式回合结束”结算机会**。

- 在死亡骑士方回合中生成：该回合结束即计第 1 次；
- 在敌方回合中生成：下一个死亡骑士方回合结束才计第 1 次；
- 第 3 次结算完成后亡魂消失。

### 2.3 感染

- 每次死亡骑士方回合末结算时，如果敌方【地面】棋位于亡魂格，该棋获得 1 层【感染】；
- 路过不触发；
- 感染与具体亡魂/格绑定；
- 离开该格前未到 3 层则清除对应感染；
- 失去【地面】同样立即清除感染；
- 再回来从 0 层开始；
- 到 3 层立即死亡，并播放“凋零”；
- 可杀死将/帅并直接终局；
- 普通战士防御与将帅铁甲不能阻止三层感染死亡；
- 【无形】但仍有【地面】的棋可被感染；感染本身不解除无形；
- 暗子可被感染，层数公开；死亡时公开真实身份。

### 2.4 与回溯

诺兹多姆完整权威快照可恢复亡魂/感染：

- 快照后新生亡魂消失；
- 已过期亡魂可恢复；
- 亡魂刷新寿命回滚；
- 感染层数回滚；
- 已清除感染可恢复；
- 若终局尚未权威结算，因感染死亡的棋可随快照恢复；
- `回溯已使用`仍属于时间线外元状态。

### 2.5 分数

死亡骑士当前确认：**50/100**；合理区间 **46–54**；置信度中等。

## 3. 骑兵畸变最新改版

旧“固定 1/3/5 兵位升级骑兵”的版本已过时。

当前规则：

- 双方各自**真实身份为马的两枚棋**升级为【骑兵】；
- 暗置时不公开/不启用骑兵额外移动；
- 揭示为马后升级为骑兵；
- 完整保留普通马的全部日字走法与蹩马腿；
- 在己方半场额外获得：**向前一步**；
- 在敌方半场额外获得：**向前、向左、向右各一步**；
- “不能后退”只约束这些新增的一步移动，不约束普通马跳；
- 新增一步既可【移动】也可【进攻】；
- 【骑兵】与【铁马】互斥。

**评分/稀有度尚未最终冻结。**本轮曾提出“40/100｜稀有”，但用户没有在结果给出后单独确认，因此不得当作最终事实写死。

## 4. 行动/关键词体系更新

旧“11 行动关键词”已被正式修改：

- 删除候选【吃子】；
- 新增【移动】；
- 新增【进攻】；
- 当前仍为 13 个行动关键词：
  **移动 / 进攻 / 耗费 / 触发 / 连带 / 操控 / 回溯 / 强迫 / 终结 / 占步 / 额外 / 揭示 / 随机**。

上位术语：
> **走棋 = 【移动】或【进攻】**

详见 `ACTION-TIER-KEYWORDS.md`。

## 5. 主着法 / 自动结算事件

- 主着法保存层级与行动关键词；
- 陷阱、感染、降落碾碎等作为后续自动结算事件；
- 自动死亡不反向把主着法改成【进攻】；
- 自动事件本身不强制使用俗手/本手/妙手层级。

## 6. 诺兹多姆回溯重走迁移

旧文本“重走不能吃子，也不能形成将军”在新行动语义下迁移为：

> **回溯后的重新走棋不能进行【进攻】，也不能形成将军。**

两个限制不能合并，因为【移动】到空位或闪将也可能形成将军。

## 7. 猎人控制陷阱 / 战士防御衰减的术语迁移

为了避免【移动】成为专用行动词后误读：

- 猎人后期控制陷阱应表达为：触发棋在其控制方下一回合**不能进行走棋/不能作为走棋主体**，而不是只写“不能移动”；
- 战士普通防御衰减应按“该棋完成成功走棋”计数，而不是只按【移动】计数；【进攻】成功同样属于走棋。

## 9. 【飞行】当前完整基线

- 获得【无形】；
- 失去【地面】；
- 免疫【碾碎】；
- 飞行期间不能进行【进攻】；
- 不占地面格；
- 同坐标允许“一地面 + 一飞行”，但空中层最多一枚飞行棋；
- 飞行本身不改变原有移动几何；
- 不能自动无视【封锁】；
- 飞行结束尝试降落；脚下有地面棋则无论敌友先结算【碾碎】；
- 若目标仍存活导致地面格未腾空，飞行棋不能完成降落并继续保持飞行；
- 降落碾碎属于自动结算，不属于【进攻】；
- 飞行持续时间由来源定义。

## 10. 【封锁】当前边界

【封锁】可限制指定格/区域的特定进入与落位行为，适用面故意较少。

- 具体限制对象由来源写明；
- 默认不是实体阻挡；
- 不自动阻断攻击线；
- 飞行/无形/非地面不能天然绕过；
- 可被来源用于限制主动移动、进攻落位、位移、回归、复活等，但不是默认全禁。

## 11. 【位移】当前边界

【位移】表示规则效果导致的位置改变，不属于走棋。

- 战士弹回 = 位移；
- 姆诺兹多退回上一位置 = 位移；
- 时光勇士回锚点 = 位移；
- 诺兹多姆整盘快照回溯不拆成逐枚位移；
- 位移是否触发陷阱/区域/封锁，由来源单独定义。

## 12. 碾碎终局统一

“碾碎他们！ / 乱杀 / 两败俱伤”改为绑定【碾碎】实际结果，不再只绑定铁马/战车来源。

因此飞行降落碾碎将/帅也适用同一终局体系。

## 13. 复活术语

当前只确认术语边界，不新增【复活】正式关键词：

- 复活：死亡事实仍成立，之后重新成为存活棋并回到棋盘；
- 回溯恢复：恢复到死亡前历史状态，不叫复活。

时光勇士沙漏回归可包含复活；诺兹多姆完整快照恢复不按逐枚复活记录。
