## 1. 基础词条与特殊位置边界

### 基础身份词条：【暗置身份】

一枚棋子处于未【揭示】状态时，凡规则需要判断其“当前棋子身份 / 兵种”，且该规则没有明确要求读取其隐藏真实身份，均使用该棋子**当前所处位置对应的棋子身份**进行判定，称为【暗置身份】。

| 当前所处基础棋位 | 【暗置身份】 |
| --- | --- |
| 车位 | 车 |
| 马位 | 马 |
| 炮位 | 炮 |
| 士/仕位 | 对应士/仕 |
| 相/象位 | 对应相/象 |
| 兵/卒位 | 对应兵/卒 |

这里读取的是**当前位置对应的基础棋位**，不是该棋隐藏的真实兵种，也不把它解释成永远绑定最初位置的身份。

- 【暗置身份】与隐藏真实身份是两个不同概念。
- 使用【暗置身份】判定不会触发【揭示】，不会改变隐藏真实身份。
- 不得仅因普通兵种判定需要而读取隐藏真实兵种，也不得通过目标合法性、资源或UI差异旁路泄露。
- 棋子正式【揭示】后，不再使用【暗置身份】，之后按已经揭示的真实兵种判定。
- 只有来源明确要求“真实身份 / 隐藏真实兵种 / 揭示后身份”，或者规则本身执行【揭示】时，才读取隐藏真实身份；后续公开范围仍遵守来源的既有信息权限。
- 本词条定义兵种判定，不自动改变控制方、阵营、揭示时机或已有移动/进攻机制。

**特殊位置边界：**若某个特殊机制允许暗子保持暗置状态而被【移置】到无法按照现有基础棋位确定【暗置身份】的位置，该机制必须自行定义此时的【暗置身份】处理。基础规则不得回退读取隐藏真实身份，也不得自动创造新的统一暗子身份；未定义的来源边界保持未定义，不擅自推定为某种兵种。

**公共判定层约束：**后续运行时实现应在游戏公共规则/判定层提供同一套【暗置身份】判定。任何英雄、畸变或基础机制在棋子未揭示时需要判断当前兵种，均优先引用该公共规则，除非该来源明确声明读取隐藏真实身份。不得仅在术士逻辑中另建暗子身份规则。本次同步只写入规则事实源与待验证合同，不声称公共运行时判定已经接入。

## 2. 术士【燃烧烈焰】引用基础规则

仍暗置的中心棋与普通目标均先按基础【暗置身份】确定兵种，再使用术士已确认的普通子力层级表：

| 兵种 | 层级 |
| --- | ---: |
| 兵/卒 | 1 |
| 士/仕、相/象 | 2 |
| 马、炮 | 3 |
| 车 | 4 |

例如，暗子当前在车位就按车的4级，在兵/卒位就按1级，不读取其实际暗藏的真实兵种。中心棋与目标适用同一规则。

本次不改中心棋必被【消灭】、普通目标层级判定公式、将帅既有终局处理、次数、占步、范围或其他技能规则；术士完整运行时接入仍须另行授权。

## 3. 旧未决项纠错

英雄设计阶段交接中的“仍暗置目标参与层级判定时，其固定公开层级如何定义”已经关闭，由基础【暗置身份】解决。

- 删除“暗置棋需要额外定义统一公开等级”的设计方向。
- 不实现“所有暗子统一视为3级”等机制。
- 不为术士建立独立的暗子身份判定体系。
- 这是基础词条新增与旧交接方向纠错，不借此重算评分、重设计英雄或恢复其他未决队列。
