状态：`BOUNDED_ENGINEERING_EVIDENCE — GLOBAL_BALANCE_NOT_PROVEN`。

## 3. 真实战术收益及对手全部首次应对

### 3.1 合成局面与作用

以下使用引擎坐标。该局面是人工构造的合法战术 fixture，**没有证明它能由某一条标准开局自然到达**；局面中只有岑缨方配置英雄，不把没有加入的其他主动英雄技能当作已穷尽反制。

| 棋子 | 坐标 |
| --- | --- |
| 红帅／黑将 | `(3,9)`／`(4,0)` |
| 红锚兵 | `(1,3)` |
| 红车 | `(4,6)` |
| 红兵／黑卒，分别限制被拉后马腿 | `(3,2)`／`(3,4)` |
| 红相 | `(1,5)` |
| 黑马，技能目标 | `(4,3)` |
| 黑车 | `(8,3)` |

双方初始均未受将。红方实际发动引缆，将黑马从 `(4,3)` 拉到 `(3,3)`，打开红车对黑将的线路。黑方获得正常应将机会，黑马自身没有合法应将着法。

### 3.2 三种首次应将逐一执行

脚本枚举了此时黑方的全部合法普通着法，确认只有以下 3 种，并分别调用真实普通行动入口执行。每种回应之后，也真实执行了红相从 `(1,5)` 到 `(3,3)` 吃马，并枚举对手能否立即回吃相。

| 黑方第一回应 | 红相吃马 | 黑方立即回吃相 | 已证明的局部结果 |
| --- | --- | --- | --- |
| 将到 `(3,0)` | 合法 | 黑车可到 `(3,3)` 回吃，已执行 | 马换相；解释性子力变化 `+1` |
| 将到 `(5,0)` | 合法 | 黑车可到 `(3,3)` 回吃，已执行 | 马换相；解释性子力变化 `+1` |
| 黑车从 `(8,3)` 到 `(4,3)` 挡将 | 合法 | 没有合法立即回吃 | 相吃马时的子力变化 `+3`；后续全局未搜索 |

车挡分支不能横走去回吃相，否则再次暴露己将。这里没有把“无立即回吃”升级成“最终必保住全部收益”，也没有搜索完整博弈树或宣称必胜。

上述全过程还执行了颜色互换、棋盘旋转的黑方镜像。两色合计 6 条第一应对分支均通过。

### 3.3 具名普通行动对照

同一初始局面还实际执行了两种不使用技能的合法分支：

- 红车直接吃原位黑马，黑车正常回吃红车：形成车换马，解释性子力变化为 `-6`。
- 红锚兵普通发展一步，黑将正常离开被车钉住的线路：双方各有正常行动，没有空过，当前物质变化为 `0`。

引缆由此展示了一种区别于直接车吃马的低价攻击机会。但这只是具名分支对照，**不是对全部普通着法的最优搜索，也不证明所有普通行动都不如技能**。

早期构造曾让红兵从 `(3,4)` 吃被拉马；审查发现该兵也可普通前进一步威胁原先被钉住的马，不能据此夸大技能优势。最终 fixture 改为黑卒堵下方马腿、红相担当低价攻击者，并以上述实际运行结果为证。

## 4. 对手可以怎样反制，哪些发动反而亏损

### 4.1 回原位：技能和正常行动形成低效交换

局面为红帅 `(3,9)`、黑将 `(5,0)`、红锚兵 `(2,3)`、黑车 `(5,3)`。红方将黑车拉到 `(4,3)` 后，黑车正常返回 `(5,3)`。

真实执行后，棋子位置完全回到原局面，岑缨已经用掉一次。这个分支证明：没有后续威胁的牵引可以被对手用普通行动撤销；有限次数不会返还。

### 4.2 吃掉锚：靠近不一定对发动者有利

在同一局面，黑车被拉到 `(4,3)` 后，也可以直接进攻 `(2,3)` 吃掉红锚兵。该分支已真实执行。

因此，锚不是免费的施法标记。它是棋盘上的真实己方棋，可能被对手抓住。玩家需要考察锚的防守、被牵动棋的新攻击范围，以及下一回合能否兑现收益。

### 4.3 炮架改变造成己将不安全：必须整体拒绝

局面为红帅 `(4,9)`、黑将 `(5,0)`、红锚兵 `(1,6)`、红兵 `(4,5)`、黑马 `(4,6)`、黑炮 `(4,2)`。

原局同线有两枚屏风，红帅安全。若将黑马从 `(4,6)` 拉到 `(3,6)`，同线只剩一个炮架，红帅受将。

真实候选枚举排除了这个动作；强行发权威请求也被拒绝。公开状态、秘密状态、资源和回合全部保持原值。红黑镜像均通过。技能不是普通进攻，但仍须承担位置变化带来的完整公开己将安全责任。

## 7. 为什么暂定两次、距离二至三格

本轮维持该参数，属于受托设计者的暂定决定，理由与证据分别列明：

1. **两次是清晰的有限资源。** 两次各占整手，不产生立即吃子，也不提供额外行动。它允许一次主要战术和一次后续调整机会；公开次数使对手能够预判。这个设计理由不等于“两次已经被统计证明最优”。
2. **二至三格把锚和目标放在可相互威胁的局部区域。** 已实跑的回位、吃锚案例说明发动者必须承担布局风险。距离 1 不开放，不能把紧贴的目标拉到锚占据格。
3. **暂未发现为可用性直接加到四格的必要证据。** 早期只读公开几何探针在 8 个普通随机演练、333 个行动边界中，二至三格有候选 236 次，二至四格为 244 次，只多 8 个“有候选”的边界。
4. **不根据单步策略零使用盲目增强。** 当前缺的是能评价延迟收益的对手和实战证据，而不是已经证明数值不足。

三格／四格探针只检验可用性：没有实际执行新技能，长局贡献的样本更多，候选存在也不代表值得发动；当时未捕获逐文件精确源哈希。因此其记录仅保留为参数取舍历史，不纳入最终测试通过数，不据此给出胜率或可用率验收。

## 8. 尚未证明什么，以及下一轮最有价值的试玩

本批没有覆盖所有英雄／畸变组合，没有完成真人强度校准、强对抗搜索、Android 真机或联网验证，也不构成全面独立 QA。合成局面能证明一种作用存在，不能证明它在自然开中残局中的出现频率或收益分布。运行不报错也不能替代上述结论。

下一轮最有价值的工作是让能理解“先花一手、再制造双重威胁”的玩家或更强公开信息策略对抗，并保留有技能／不用技能的真实可选行动：

- 记录每次候选出现时，玩家是否愿意发动，以及不发动是因为无收益、成本过高、目标过少，还是未看懂后续用途。
- 重点观察对手回位、主动吃锚、用将军压制发动窗口、牺牲低价子拆除锚点的成功频率。
- 分开统计开放后的中局机会与早期背刺终局，避免把“对局提前结束，尚未到技能窗口”混成技能完全不可用。
- 使用相同源版本、先后手和公开信息约束，比较保留两次的机会成本；有具体过强／过弱证据后，再决定是否调整次数或距离。

在得到这些证据之前，参数保持 **每局 2 次、距离 2—3、占整手**。这是有边界的候选取舍，不是正式平衡验收，也不预填主线、玩家或其他对话的认可。
