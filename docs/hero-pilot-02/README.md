## 运行与试玩

沿用原仓命令，在仓库根目录运行；需要 **Node.js 24 或更高版本**，游戏运行和测试无需安装依赖。

```bash
npm run serve:web
```

服务器默认端口为 4173。打开：

[本机第二英雄试点](http://127.0.0.1:4173/web/?heroPilot2=1)

使用终端给出的其他主机或端口时，仍在 `/web/` 后加 `?heroPilot2=1`。请选择本机现有揭棋，再选择岑缨。该流程在真实引擎和现有游戏页面内运行。

原仓测试、构建命令：

```bash
npm test
npm run build:web
```

也可直接使用 Node：

```bash
node --test --test-reporter=spec tests/*.test.ts
node scripts/build-web.ts
node scripts/serve-web.ts
```

第二英雄引擎专项可单独运行：

```bash
node --test --test-reporter=spec tests/hero-pilot-02.test.ts
```

构建输出沿用 `dist/`。以上是可复现命令，不代表读者已经执行或通过。
