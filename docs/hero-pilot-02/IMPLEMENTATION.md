## 实现结构

| 部位 | 文件与行为 |
|---|---|
| 公开候选 | `src/hero-cen-ying.ts` 只读取 GameState，以控制方、可见性、空间层、直线距离、地面阻挡、堡垒及己将安全筛选；落点由权威计算 |
| 权威结算 | `src/hero-actions.ts` 接受 `tether_pull` 与锚／目标 ID，复用既有行动、落位、消灭、回合与快照管线；不接受客户端任意终点 |
| 历史与资源 | 公开每方成功次数，整手占步，真实 from/to、II 级、英雄来源及落位记录；无普通移动收益冒领 |
| 终局判定 | `src/rules.ts` 的合法行动判断纳入引缆，防止存在合法引缆仍被判无棋可走 |
| 英雄登记 | `src/heroes.ts` 的实验名录与默认 19 人名录分开；`src/game.ts` 拒绝非 jieqi 模式选择岑缨 |
| 选人／战斗 | `web/hero-pilot-02.ts`、独立 CSS 与 `web/app.ts`：仅 URL 显式开关、本机 jieqi 入池，头像／立绘、公开次数、锚和目标选择及落点预览 |
| 美术 | 两张 PNG 母版、原提示词与哈希；运行时两个 WebP 头像尺寸和透明立绘，合计 135,188 bytes |
| 构建与服务 | 复制独立试点 CSS，提供正确 PNG／WebP MIME；不重写 Android 资产快照或生成 APK |

候选生成不读取秘密身份、陷阱或真正主帅宿主。真实成功落位仍执行既有秘密效果，不能借“预览安全”提前泄密或要求退还合法发动成本。落位来源的 `beforeController` 记录被拉敌棋的控制方。

## 交互中的原子性

玩家先选己方锚，再选敌方目标；界面显示实际一格位移与占整手代价，允许取消。打开弹窗时绑定 revision 与 actionId，确认时再次经权威检验。

过期请求测试曾暴露 UI 同步 trap 列表会给原私有状态补入空数组。现已对引缆使用独立 actionSecret 副本，失败不改私有状态；其他英雄同步路径保持。重复 actionId 在状态写回与成功消息之前返回。成功后清除旧的刺杀／强袭武装，再进行本机私密换手，避免下一方普通走子误用上一方选项。

检查也补上取消按钮、非岑缨图片降级标记清理。最后落点高亮来自真实被拉棋坐标，没有使用占位 `(0,0)`。

## 仍未验证的范围

本机 Chromium 启动被环境的 Unix socket 权限拒绝（`socket() failed: Operation not permitted`）；提供的云浏览器也无法访问本机预览地址（连接拒绝）。本轮没有取得真实浏览器画面，**不能标成浏览器试玩、触摸适配或真机验收通过**。模拟 DOM 不计算真实 CSS 布局、不解码图片，不覆盖网络输送与设备尺寸体验。

16 局允许／禁用技能的单步公开策略全部零次发动、两臂同轨。另 4 局刻意在可用时优先引缆才覆盖到技能；它们的胜负不能作为平衡评级。详见 [BALANCE.md](BALANCE.md)。尚需真实浏览器和真人对抗或更强公开信息策略，独立 QA 也未完成；本轮同行只读复核不冒充独立验收。

## 复现

运行和专项命令见 [README.md](README.md)。补充检查：

```bash
node scripts/review/hero-pilot-02-balance.ts
```

DOM 检查使用审查环境额外安装的 `jsdom@26.1.0`，不添加到游戏运行依赖；需先构建 Web：

```bash
npm install --prefix /tmp/lezi-dom --no-save --ignore-scripts jsdom@26.1.0
JSDOM_MODULE=/tmp/lezi-dom/node_modules/jsdom/lib/api.js node --experimental-vm-modules scripts/review/hero-pilot-02-dom.mjs
```

审查夹具仅在内存追加到构建模块，没有产品调试入口。对局脚本重跑会覆盖其结果 JSON 为原始详细日志；当前保存版已做去重复瘦身，保留所有动作、种子、状态哈希与后处理说明。
